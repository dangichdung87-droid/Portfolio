# Dang Ich Dung - Portfolio

Personal frontend portfolio built with HTML, CSS and JavaScript.

## Features

- Responsive design
- Mobile navigation
- Project category filtering
- Project detail modal
- Accessible semantic HTML
- Contact form UI
- GitHub Pages compatible

## Run locally

Open `index.html` in a browser.

## Before publishing

1. Replace `images/profile.jpg` with your own real profile photo.
2. Replace `your-email@example.com` with your real email.
3. Replace the GitHub link with your GitHub profile.
4. Review project descriptions and change anything that does not exactly match your work.
